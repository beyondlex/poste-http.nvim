## Fixed this round

1. **copy.lua multipart `-F` path bypassed `seed_random`** — `{{$uuid}}`/
   `{{$randomInt}}` inside a multipart part value were generated with raw
   `math.random` in `build_multipart_flags`, so the first copied value
   repeated across sessions (LuaJIT's fixed per-process seed) — the same
   root cause the 2026-09-16 round fixed in the resolver/form_data paths,
   missed in this caller. `copy_as_curl` now arms `util.seed_random()`
   before building the flags.
2. **copy.lua multipart `-F` path dropped block-level `@vars`** — the flags
   were resolved against a variable map rebuilt from FILE-level vars +
   env only; a part value referencing a block-level `@tok` copied as the
   literal `{{tok}}`. `collect_vars` takes the raw block lines now and
   merges block defs over file defs (resolver precedence).
3. **history persist wrote `_jq` to disk** — any `add_entry` after a jq
   filter re-encoded the whole list including earlier entries' `_jq`
   (query + filtered lines + original_lines, up to 2x body size per
   entry), bloating history.json and resurrecting stale filters on load.
   persist() nils `_jq` around the encode. Note: the existing
   "drops the transient _jq field" spec was a FALSE POSITIVE — it set
   `_jq` after add_entry had already persisted; it now performs the
   realistic two-add sequence.

## Recorded, not fixed (uncertain / deliberate)

- **`cache.extract_request_block` (describe-fails fallback) doesn't skip
  pre-script lines** — a block opening with `< {% ... %}` can yield
  `request_line = "< {%"` (its skips cover only comments/`<<`). Reachable
  only when tree-sitter describe returns nothing; `find_request_line` has
  the correct skip set — align them next time the file is touched.
- **`response_parser.parse_response` final_url from `Location:` verbatim** —
  a RELATIVE redirect leaves final_url relative (curl's `%{url_effective}`
  would be the robust primary source). Display-only impact today.
- **shell-escape strings starting with `-` pass through unquoted** in both
  `util.shell_escape` and copy.lua's variant when they contain no other
  special char — a value like `-foo` after a flag position could parse as
  a flag in the COPIED command string. Low risk (paste output, not
  executed by us), noted for the next util pass.
- **`run.start_curl_exec` unresolved-var gate checks header VALUES only** —
  a `{{var}}` in a header NAME slips past the fail-fast check and goes to
  curl literally. Rare; same family as the value checks, cheap to add.
- **`state.set_responses(chain, idx)`**: `idx or (#chain or 1)` errors on a
  nil chain — contract says chain is always a table; guarded only by that.
- **`history.show` on very narrow terminals** — detail_width = total − 53 − 2
  can reach ≤ 0 below ~60 columns and error inside float.open. Edge case.
- **`vars.load_env_vars_with_lines` brace counting ignores braces inside
  JSON string values** — a value containing `}` corrupts the section scan.
  Hand-rolled by design (line numbers for `gi`); a real JSON parser can't
  give lines, so brittleness is the accepted tradeoff.
