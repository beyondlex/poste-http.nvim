# Review Notes — 2026-09-22

Scope: full test baseline (109 spec files green at start) + a ledger-driven
pass: every "recorded, not fixed" item from the 09-16…09-21 notes was

deprecated-API sweep and luacheck hygiene.

## Fixed this round

1. **curl import: combined short-flag blobs now consume value flags
   getopt-style** — `-sSo out.txt` walked every letter as boolean, so
   `out.txt` leaked as a bare arg and won the first-bare-arg-is-URL scan;
   the imported request targeted a local file. The generic branch walks the
   letters: a value flag (`o/H/X/d/F/u` + the ignored-value set) takes the
   rest of the blob as its attached value (`-sofile`) or the next argv when
   it ends the blob. Spec: `tests/http/curl_spec.lua`.
2. **shell_escape: copy.lua's drifted variant consolidated; curl_exec guards
   the free-position URL with `--`** — live curl 8.7.1 netcat probe (below)
   disproved the 09-17 fear that a leading-dash value "parses as a flag":
   getopt consumes the next argv as the optarg regardless of quoting. The
   only free-position argument is the trailing URL, so `curl_exec` now emits
   `--` before it (the real guard; quoting cannot change curl's argv parse).
   copy_as_curl escapes through `util.shell_escape` (whitelist dialect)
   instead of a private blacklist copy that quoted fewer inputs.
   Specs: `tests/http/curl_exec_spec.lua`, `tests/http/copy_spec.lua`.
3. **env.json section scan ignores braces inside string values** — the
   `{`/`}` counter read every byte, so a legal value like `"open": "{"`
   pushed the section boundary out and the NEXT env section's keys leaked
   into the lookup (later sections overwrite earlier keys). Counting now
   tracks JSON string state. Spec: `tests/http/vars_spec.lua`.
4. **import: a dotted reference that is a literal request name resolves** —
   `resolve_reference` parsed any dotted name as `alias.Name` and returned
   nil on an unknown alias; a bare import's request named `Get User.v2` was
   unresolvable. Alias form keeps precedence; a miss falls through to the
   bare-name scan. Spec: `tests/http/import_spec.lua`.
5. **history: narrow-terminal geometry** — `detail_width = total − 53 − 2`
   went negative below ~56 columns and nvim_open_win refused it, so
   `:PosteHttpHistory` opened and instantly tore itself down. New pure
   `M._layout_widths(avail)` shrinks the list first (columns.render
   truncates to the given width) and floors the detail pane at 20 columns;
   wide terminals keep 53 + remainder. Spec: `tests/http/history_spec.lua`.
6. **assertions: `response.headers[nil]` / non-string keys return nil** — a
   raw table yields nil; the case-insensitive `__index` called `k:lower()`
   on the key instead, crashing user scripts on harmless lookups.
   Spec: `tests/http/assertions_spec.lua`.
7. **state: `set_responses(nil, nil)` is total** — the `idx or (#chain or 1)`
   inner fallback was unreachable (`#nil` errors instead of yielding nil).
   Explicit branches: explicit idx wins, table chain defaults to its length,
   nil chain clears the index like `set_response(nil)`.
   Spec: `tests/http/state_contract_spec.lua`.
8. **folding: per-buffer separator caches evicted on BufWipeout** — every
   closed buffer leaked a cache entry under its bufnr forever. Lazily-armed
   autocmd drops the entry; `M._evict`/`M._cache_size` exposed for tests.
   Spec: `tests/http/folding_spec.lua`.
9. **luacheck 13 → 0 warnings** — `.luacheckrc` now declares the sandbox
   globals (`client`/`response`/`request`) for `examples/` scripts instead
   of warning on each use; plus a `vim.bo` deprecation cleanup in
   plugin/poste.lua.

## Ledger closures (probe/verification evidence)

- **shell-escape leading `-`** (09-17, carried 09-18/09-19): CLOSED as a
  misdiagnosis. Probe: `curl -X POST --data-binary -foo URL` against a
  netcat listener sent `Content-Length: 4` with body `-foo` — getopt consumes
  the next argv as the option's value even when it starts with `-`, for both
  short and long flags. Shell quoting therefore cannot change flag parsing
  at all; `--` before the URL (fixed above) is the only real guard for the
  one free-position slot.
- **`env.sync_winbar` claims `.rest`** (09-18): CLOSED as consistent —
  `ftdetect/poste.vim` maps `*.rest` to `poste_http`, so the winbar match is
  correct, not drift.
