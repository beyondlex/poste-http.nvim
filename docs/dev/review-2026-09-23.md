## Fixed this round

1. **indicators: spinner-timer cleanup hung on BufDelete, which never fires
   for scratch buffers** — `nvim_buf_delete` on an unloaded scratch buffer
   (the normal `.http` case) fires only `BufWipeout`; probed headless:
   BufDelete=0, BufWipeout=1. A request wiped mid-run (`:%bd`, tab close)
   therefore leaked its uv spinner timer ticking over a dead buffer forever.
   The autocmd now hooks BufWipeout and shares `M._evict` / `M._spinner_count`
   (folding.lua's eviction precedent, same shape). Spec:
   `tests/http/indicators_eviction_spec.lua` (+2, real buffers).
2. **util.redacted_cmd printed URL userinfo and `-u` values verbatim** —
   every executor logs its argv here; sensitive `-H` headers were covered,
   but `POST https://bob:secret@host/…` (legal in a `.http` request line)
   logged the password, and an `-u bob:pass` argv value — a credential
   outright — passed through. New `util.redact_url_userinfo` (poste-mq
   util.redact_url's rule: authority-scoped, split at the LAST @) applied to
   URL-shaped args, plus a `***` slot for `-u/--user`. Specs:
   `tests/util_spec.lua` (+2).
3. **ai/blocks.dep_names diverged from the executor's reference grammar** —
   it matched only `[%w_]+` before `.response.`/`.request.`, while
   `request_deps.split_request_ref` (the documented contract) takes
   everything before the marker and normalizes `.res.` → `.response.`.
   `{{Login User.response.body}}` ran as a dependency but never appeared in
   the chat's auto-context. Spec: `tests/http/ai_blocks_spec.lua` (+1).
4. **image_cache: download URL now guarded with `--`** — the preview-image
   fetch builds its own curl argv and left the URL (often harvested from a
   response body) as the unguarded free-position argument. Same shape
   curl_exec closed in the 09-22 round. Spec pins the argv shape.
5. **ai/init: ask_request no longer writes "env `nil`" into the prompt**
   when no environment is bound (an invitation for the model to invent one).

## Recorded, not fixed (uncertain / deliberate)

- **ai/actions.poll_completion stale-response race**: the poller treats a
  non-nil `state.last_response` as success; if `run_request` ever bails
  before raising `_busy`, the first tick could report the PREVIOUS run's
  response as the outcome. Needs a run-scoped completion marker (e.g. a
  generation counter in state) rather than a local patch — recorded for
  whoever touches the run pipeline next.
- **copy_as_curl magic-var duplication** (09-22, carried).
- **import_postman bakes collection-variable VALUES**; **json.get_key_paths
