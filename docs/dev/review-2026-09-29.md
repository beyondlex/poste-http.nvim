## Fixed this round

1. **`VarResolver:substitute(nil)` crashed** on `result:gsub` — every
   current caller hands a string, but the resolver is public API and the
   family contract (poste-mq `vars.expand`) passes non-strings through.
   Now: non-string input returns unchanged. Spec: `tests/http/vars_spec.lua`.
2. **`nested_access.get_nested_value(obj, 5)` crashed** at `#path` — the
   resolver is reachable from scripted jq filters, so a non-string path
   now reads as "nothing found". Spec:
   `tests/http/zero_coverage_smoke_spec.lua`.
3. **One non-numeric entry id dropped the whole persisted history** —
   `history.load()` guarded on truthiness, so a hand-edited `"id": "abc"`
   threw on `e.id > max_id`; the setup-time pcall swallowed it and every
   entry from the file silently vanished. Guard on the type: corrupt
   entries are skipped, good ones still load and the counter restores.
   Spec: `tests/http/history_persistence_spec.lua`.
4. **Dead branch in the curl importer's blob walk** — the inner
   `elseif letter == "I"` arm could never run: `I` is handled as a boolean
   letter before the `value_short` branch. Removed; no behavior change.

## Recorded (uncertain / intentional)

- **Nested wildcards collect per-element results without flattening** —
  `items[].tags[]` over items with `tags = {"x","y"}` yields
  `{{"x","y"}}`, not jq's streamed `x, y`. No current consumer walks a
  double wildcard, so it is ambiguity, not breakage — but the jq filter
  work should decide the contract (flatten vs nest) before a consumer
  exists.
- **A resolver value containing `{{` merges into the pattern scan** —
  `@a = {{` makes `[{{a}}]` substitute to `[{{]`. Bounded by the 20-round
  cap, pathological input only; a value-escaping pass would fix it but
  none of the documented variable sources can produce it today.
- **`format_assertions` shows the ✘ icon when a run produced zero tests
  and zero errors** (the summary bar computes all_passed from
  `#tests > 0`). The ⓘ hint below explains it; cosmetic.

## Lessons (this round)

- **Corrupt-entry guards must skip, not abort the batch** — the third bug
  of this class in the family (mq toml sections, mq env keys, now history
  ids). When a loader validates entries one by one, a bad entry's cost is
  that entry, never the file.
- **Cross-family probing pays again** — the nil-input guard contract was
  copied from poste-mq's `vars.expand`; running both suites in one round
  surfaced the same hardening gap on this side within hours of each other.
