# Review Notes — 2026-10-07

Scope: full test baseline (118 spec files green at start) + fresh reads
of util/history/json/md5/ws_session/orchestration/import/columns/
vars/format dispatcher + adversarial probe batteries (throwaway nvim
scripts before any fix) against surfaces the previous rounds had not
attacked: hand-edited history.json INNER fields, non-string entries on
render paths, hostile buffer content through describe.lua, hostile curl
output through response_parser, and the ai/ module family.

## Fixed this round

1. **history.load's sanitize boundary stopped one level too shallow** —
   its comment promises "a drifted field is dropped here … instead of
   raising mid-render in format_view", but the implementation only
   checked `response` / `assertion_results` / `script_logs` as wholes.
   A hand-edited `{"response": {"headers": 42}}` (or body=7,
   content_type=8, metadata="x") sailed through and crashed the detail
   views (`ipairs` over a number, `#` on a number, `:match` on a
   number). The inner fields now sanitize under the same contract; a
   spec asserts every detail view renders the sanitized entry.
   Spec: `history_persistence_spec`.

2. **ws_session.send could throw into the keymap handler** — chansend
   raises "invalid channel id" in the window where the process died but
   on_exit has not finalized the session. The amqp transport and
   poste-mq's session_conn carry exactly this pcall guard; the http
   interactive session was the missing third copy (the family rule:
   when you fix a cross-cutting guard, grep the siblings in the same
   commit). A failed write now notifies and reports false without
   finalizing the session. Spec: `ws_session_spec`.

3. **Non-string entries on shared render paths converge through
   tostring** — `buffer.sanitize_lines` indexed a number entry; `ui/
   text.truncate/middle` raised on numbers/booleans. Both are shared
   boundaries fed from hand-built rows and scripted values.
   Specs: `buffer_spec`, `ui_text_spec`.

4. **ai/blocks + ai/mentions entry points tolerate non-string input** —
   `method_of_text` guards with `type(text) ~= "string"`; its siblings
   `truncate` (# on nil), `title_of_text` (vim.split on a number) and
   `mentions.match` (:match on a number) raised on the same values.
   Not reachable from current call sites (both truncate callers
   pre-guard) — fixed for consistency with the module's own
   convention. Specs: `ai_blocks_spec`, `ai_mentions_spec`.

## Probe batteries that passed (no change)

- **describe.lua against 19 hostile buffer shapes** — `###` alone,
  no-URL request lines, lowercase methods, CRLF, colonless headers,
  duplicate headers, unterminated `> {%`, 5000-char request lines,
  CJK/pipe-braced names, NUL bytes in bodies, 1000 tiny blocks: all
  parse total, every consumer-shaped field walk survives.
- **response_parser against hostile curl output** — garbage status
  tokens, empty/nil stdout entries, missing body files, binary PNG
  magic, 500 status lines, invalid-UTF-8 stderr through parse_error:
  all total.
- **executors / columns.render / format dispatcher** — boolean cells,
  nil rows, `headers = 42` at the dispatcher (now handled by fix 1 at
  the load boundary), hostile `detect_filetype` content types.
- **import cycles impossible** — `build_import_index` is flat (each
  imported file read once, no transitive following), so a↔b import
  loops cannot recurse; orchestration's client.run resolves against
  IMPORTED files only and executes via curl, so no same-buffer
  self-recursion and no unbounded stack growth (poste-mq needed its
  depth guard for a different shape).
- **curl_exec `--` invariant verified in place** — the URL sits behind
  `--`, closing the leading-`-` concern recorded on 10-06.

- **`_layout_widths` floors the list at 24 columns** — under ~46 editor

## Lessons (this round)

- **A guard's comment can outlive its guard's scope** — the history
  boundary read like it covered "the fields the views index" while the
  code covered three top-level keys. When a comment claims a
  boundary "drops drifted fields", the spec must enumerate the fields
  it claims to cover, not just one witness.
- **The chansend death-race guard now has three copies** (amqp,
  poste-mq session_conn, ws_session). Same rule as 09-23's redaction
  lesson: a cross-cutting guard found in two places means grep the
  third sibling in the same round.
